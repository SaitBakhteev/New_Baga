### Заметки по наименованию calback_data инлайн-кнопок списка тренировок
**1. Нужно ориентироваться на user flow выбора тренировки:**
<ul>
    <li> <b style="color: blue ">/event</b> <i style="color: aquamarine"> #выбрать тренировку</i>↓</li>
    <li> <b style="color: forestgreen ">Тип тренировки </b>↓</li>
    <li> <b style="color: darkslategrey ">Список тренировок выбранного типа </b>↓</li>
</ul> 

**2. Основная концепция наимепнования `callback_data` для инлайн-кнопок:**
- минимизация оперирования данными state
- следовательно тип тренировки идет в `callback_data`
- в оперативную память state по максимум должны идти данные из `callback_data` нажатой инлайн-кнопки

**3. Кнопки, закрепленные за выбранной тренировкой:**
- `Записаться на тренировку`. Здесь можно назвать `calback_data` как 
`"sign_up_for_training__event_id:{event_id}"`
- `Записать друга`. Здесь понадобится state, поскольку операция требует подтверждения. Можно назвать `сalback_data`
как `"sign_up_friend__event_id:{event_id}"`. После этого `event_id` идут в память *state*
